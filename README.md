## Cara menjalankan
Butuh Python dengan tkinter (di Linux biasanya paket `python3-tk`).

    cd siapkumpul
    python main.py
    python -m unittest discover -s tests

## Struktur
main.py, demo_polymorphism.py, ui/ (tampilan tkinter), models/ (entitas), services/ (alur pemeriksaan), utils/ (fungsi bersama), tests/.
